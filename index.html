Process

From repo to
published app

AppExplorer turns any GitHub repository into a publishable app in three steps. No review board. No waiting.

01
Sign in

Authenticate with your GitHub account. AppExplorer reads your repositories using your OAuth token — securely and privately.

github oauth
02
Add the folder

Create an appos/ folder in your repo. Drop in an icon and a markdown description file.

appos/icon.png
03
Link & publish

Connect the repository from your dashboard. Works with public and private repos — source code is never exposed to end users.

live instantly

Convention

One folder.
That's all.

Add an appos/ folder to any repository. AppExplorer detects it automatically and populates your app's listing — icon, name, description, everything.

  • → appos/icon.png (or .jpeg)
  • → appos/appos-appinfo.md
